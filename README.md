# CPI Toolkit

A browser extension with developer tools for SAP Cloud Integration, for Google Chrome and Microsoft Edge 117 or newer:
message logs, traces, Quick Review, an iFlow builder, generated tests and an optional AI assistant that works only with
an AI service you configure. **Version 5.0.1 is a beta.**

**Independent project.** CPI Toolkit is not an SAP product and is not affiliated with or endorsed by SAP SE. SAP, SAP
Integration Suite and SAP Cloud Integration are trademarks of SAP SE.
