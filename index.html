CPI Toolkit

Developer tools for SAP Cloud Integration

A browser extension for Google Chrome and Microsoft Edge (117 or newer) that adds tools to the Cloud Integration web pages and a side panel: message logs, traces, Quick Review, an iFlow builder, generated tests and an optional AI assistant that works only with an AI service you configure. Version 5.0.1 is a beta.
